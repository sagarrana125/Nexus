# Nexus.
My personal learning hub for Data Science, Machine Learning, and beyond. Built with plain HTML, CSS, and JavaScript, on the Insanely Simple philosophy.

---

## What
One place for the resources I'm actually using right now — courses, a book, a reference, and a blog. No clutter. No distractions. Just learning.

---

## Tech
- HTML + CSS
- Vanilla JavaScript
- Google Fonts (Fraunces + Inter)
- GitHub Pages

## Principles
- **Brutal** — No fluff. Direct.
- **Small** — Only a handful of resources. Focused.
- **Minimal** — Whitespace. Clean.
- **Iconic** — SVG line art. Visual.
- **Phrasal** — Clear names. Memorable.
- **Simple Stick** — Cut the noise.

## Project structure
```
Nexus/
├── index.html        # Homepage markup
├── chaicode.html      # Chaicode detail page
├── css/
│   └── style.css       # All styling — tokens, layout, light/dark theme
├── js/
│   ├── data.js           # Resource content — edit here to add/remove cards
│   ├── app.js              # Renders the resource grid from data.js
│   └── theme.js             # Light/dark mode toggle
├── README.md
└── LICENSE
```

---

## Setup
```bash
git clone https://github.com/sagarrana125/Nexus.git
cd Nexus
# Open index.html in browser
```
No build step, no dependencies to install — fonts load from a CDN, everything else is static.
